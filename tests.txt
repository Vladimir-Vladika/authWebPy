Начало работы с Flask и расширением SQLAlchemy
Установка необходимых пакетов
Установка Flask и расширений:
Flask — это микрофреймворк для разработки веб-приложений на Python;
Flask-SQLAlchemy — это расширение для Flask, которое упрощает работу с базами данных.
Установим нужные пакеты:

Переходим в Python Packages.
Находим Flask-SQLAlchemy.
Нажимаем на кнопку Install package.
Находим Flask.
Нажимаем на кнопку Install package.
Команды для установки через терминал:

pip install Flask
pip install Flask-SQLAlchemy
Создание приложения Flask

1. Импортируем модули:

from flask import Flask
from flask_sqlalchemy import SQLAlchemy
2. Создаём приложения и настраиваем базу данных:

app = Flask(__name__)
app.config['SQLALCHEMY_DATABASE_URI'] = 'sqlite:///example.db' # Эта строчка нужна, чтобы мы могли подключиться к базе данных
app.config['SQLALCHEMY_TRACK_MODIFICATIONS'] = False # Эта строчка отключает сигнализацию об изменении объектов внутри базы данных
db = SQLAlchemy(app) # Создание объекта, через который мы будем работать с базой данных
Определение модели базы данных

1. Создаём модель User:

class User(db.Model): # В скобках указываем модель, чтобы в дальнейшем создать именно базу данных
    id = db.Column(db.Integer, primary_key=True)
    username = db.Column(db.String(80), unique=True, nullable=False) # В скобках описываем поля таблицы

    def __repr__(self): # Этот метод определяет, как объект модели будет выглядеть в виде строки
        return f'<User {self.username}>'
Описание полей модели в скобках:

id — целое число, первичный ключ.
username — строка длиной до 80 символов, уникальная, не может быть пустой.
Создание базы данных

1. Создаём таблицу в базе данных:

with app.app_context(): # Функция создаёт контекст приложения, который нужен для работы с базой данных
    db.create_all() # Создание всей таблицы, которые определены в классе User
Работа с базой данных

Добавление новых пользователей

1. Создаём маршрут для добавления пользователей:

@app.route('/add_user') # С помощью декоратора создаём маршрут, который будет вызывать функцию
def add_user(): # Функция будет создавать объект класса User
    new_user = User(username='new_username')
    db.session.add(new_user) # Добавляем в сессию
    db.session.commit() #  Сохраняем изменения в базу данных
    return 'User added' # Вывод сообщения о том, что юзер добавлен в базу данных
Сессия — временное хранилище перед добавлением в базу данных.

----------------Получение данных из базы данных

1. Создаём маршрут для получения всех пользователей:

@app.route('/users')
def get_users():
    users = User.query.all() # Получаем всех юзеров из базы данных и сохраняем в переменную users
    return str(users)
Рассмотрим использование расширения Flask WTF, которое облегчает работу с формами в Flask, помогает создавать формы, валидировать (проверять поля) формы.

---------------Установка необходимых пакетов

1. Устанавливаем Flask WTF с помощью Python packages или через терминал:

pip install flask-wtf
Импортируем модули:

from flask import Flask, render_template, redirect, url_for
from flask_wtf import FlaskForm # Это базовый класс для создания форм
from wtforms import StringField, SubmitField # Это классы для создания полей внутри формы
from wtforms.validators import DataRequired # Валидатор, нужный для проверки
Настройка приложения Flask

-----------------Создание и настройка приложения

1. Создаём приложения Flask:

app = Flask(__name__)
2. Создаём секретный ключ для защиты форм:

app.config['SECRET_KEY'] = 'your_secret_key'
Создание формы с использованием Flask WTF

-------------------Определение формы

1. Создаём класс для создания формы:

class NameForm(FlaskForm): # Используем FlaskForm в качестве родительского класса
    name = StringField('What is your name?', validators=[DataRequired()])
    submit = SubmitField('Submit')
--------------------Описание полей формы:

name — текстовое поле с меткой "What is your name?" и валидатором, проверяющим, что поле не пустое;
submit — кнопка для отправки формы.
Создание маршрута для отображения и обработки формы

--------------------1. Создаём маршрут для главной страницы:

@app.route('/', methods=['GET', 'POST']) #  С помощью этого маршрута мы сможем и отправлять, и получать информацию
def index():
    form = NameForm() #  Создаём объект формы
    if form.validate_on_submit(): # Проверка того, прошла ли форма валидацию и вообще отправлена ли она
        name = form.name.data #  Получаем значение из формы, информацию из этого значения. Сохраняем в переменную
        return redirect(url_for('hello', name=name)) # Отправляем пользователя на новую страницу, передаём полученное имя
    return render_template('index.html', form=form)
------------------2. Создаём маршрут для отображения приветствия:

@app.route('/hello/<name>')
def hello(name):
    return f'Hello, {name}!'
-----------------3. Заканчиваем программу:

if __name__ == '__main__':
    app.run(debug=True)
Шаблон для отображения формы

--------------1. Создаём шаблон index.html:

<!doctype html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <title>Flask WTF Form</title>
</head>
<body>
    <h1>Flask WTF Form</h1>
    <form method="POST"> # Указываем метод, потому что что нам нужно только отправлять данные
        {{ form.hidden_tag() }}
        <p>
            {{ form.name.label }}<br>
            {{ form.name(size=32) }}
            {{% for error in form.name.errors %} # Отображение ошибок валидации
                <span style="color: red;">[{{ error }}]</span>
        </p>
        <p>
            {{ form.submit() }}
        </p>
    </form>
</body>
</html>
------------------Описание элементов шаблона:

form.hidden_tag() — скрытое поле для защиты от CSRF-атак. Проверяет сервер при получении данных. Если какая-то программа попытается взаимодействовать с формой, сайт об этом сигнализирует;
form.name.label — метка для текстового поля. Значение label указано в файле main.py;
form.name(size=32) — само текстовое поле с указанной шириной;
form.submit() — кнопка отправки формы.
